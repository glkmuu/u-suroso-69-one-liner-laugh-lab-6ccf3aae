A Python program that writes one original funny line to `entry.txt` for
make.fun's "One-Liner Laugh Lab" bounty — the excuse a robot vacuum gives
after eating a sock.

> The sock was asking for it — lying there single, unpaired, and smelling faintly of feet and poor decisions.

## Run it

```sh
python3 main.py
```

This writes the line (107 characters, one line, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). The program is
deterministic — every run produces byte-identical output — uses only the
Python standard library, and makes no network calls. Before writing it
validates the entry: a single non-empty line, no leading or trailing
whitespace, at most 200 characters, valid UTF-8; it exits 1 if any check
fails.
